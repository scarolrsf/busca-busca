# Documentação compartilhada do projeto

A pedido de Sarah, a documentação fica em dois arquivos na raiz: **README.md**, com o estado atual (requisitos, arquitetura, dados, operação, conferências e pendências em aberto), e **HISTORICO.md**, com o registro datado das alterações.

Leia o README.md e o AGENTS.md antes de iniciar ou retomar trabalho. Toda alteração deve incluir, na mesma entrega, atualização das seções afetadas do README e uma entrada datada no topo do HISTORICO.md, conforme a seção “Regra permanente de atualização” do README. Registre o que mudou, por quê, arquivos, validação, dados/implantação afetados e pendências. Não mantenha um histórico paralelo neste arquivo.

A divisão combinada é Claude Code na interface e Codex na revisão de arquitetura e dados, salvo nova orientação de Sarah. Durante trabalho simultâneo, releia a versão mais recente do README e do HISTORICO antes de gravar e preserve o registro do outro colaborador. Diferencie prévia local, fonte consultada de verdade e versão publicada no GitHub Pages.

Estas instruções não instalam monitoramento de arquivos; cada entrega deve manter a documentação atualizada.
