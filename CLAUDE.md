# Documentação compartilhada do projeto

A pedido de Sarah, use **README.md**, na raiz, como o único documento principal de requisitos, arquitetura, dados, operação, testes, pendências e histórico.

Leia o README.md e o AGENTS.md antes de iniciar ou retomar trabalho. Toda alteração deve incluir, na mesma entrega, atualização das seções afetadas e uma entrada datada no histórico do README, conforme a seção “Regra permanente de atualização deste documento”. Registre o que mudou, por quê, arquivos, validação, dados/implantação afetados e pendências. Não mantenha um histórico paralelo neste arquivo.

A divisão combinada é Claude Code na interface e Codex na revisão de arquitetura e dados, salvo nova orientação de Sarah. Durante trabalho simultâneo, releia a versão mais recente do README antes de gravar e preserve o registro do outro colaborador. Diferencie prévia local, fonte consultada de verdade e versão publicada no Google.

Estas instruções não instalam monitoramento de arquivos; cada entrega deve manter a documentação atualizada.
